PHP Guard

Injection protection that runs before every request. Blocks SQL injection, XSS, path traversal, remote file inclusion, command injection, PHP-CGI argument injection (CVE-2024-4577) and PHP file uploads, hides X-Powered-By, and sends security headers.

; php.ini or .user.ini
auto_prepend_file = "/var/www/php-guard.php"

Start with 'mode' => 'log' for a few days to check for false positives, then switch to block. This adds a layer; keep using prepared statements and output escaping.

Download php-guard.php

PHP Auto-Updater

Installs patch releases for the branch you run (apt, dnf, yum, apk, Homebrew), restarts PHP-FPM / Apache, and warns when your branch is end-of-life or your OS repo lags behind php.net.

sudo install -m 755 php-auto-update.sh /usr/local/sbin/
sudo php-auto-update.sh --dry-run
# daily via cron:
17 3 * * * root /usr/local/sbin/php-auto-update.sh >> /var/log/php-auto-update.log 2>&1
Download php-auto-update.sh

Self-check script

Reports your exact PHP version, whether it is outdated or end-of-life, which listed CVEs apply, and which php.ini settings need hardening. Exit codes make it easy to alert from cron or CI.

php php-version-check.php
# exit 0 = ok, 1 = outdated/warnings, 2 = end-of-life
Download php-version-check.php
Version data is refreshed daily from the php.net releases API. Source on GitHub.
